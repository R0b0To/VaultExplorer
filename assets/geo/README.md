# cities.bin

Offline list of cities (population 5000 and up) used by the gallery filter to name the place of a
photo from its GPS position. Rebuild it with `scripts/build_gazetteer.py` (the header of that script
describes the file format).

Data: GeoNames (https://www.geonames.org), licensed CC BY 4.0
(https://creativecommons.org/licenses/by/4.0/).
